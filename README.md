# task-api

[![CI](https://github.com/denagava/task-api/actions/workflows/ci.yml/badge.svg)](https://github.com/denagava/task-api/actions/workflows/ci.yml)
![Go](https://img.shields.io/badge/Go-1.23-00ADD8?logo=go)

REST API для управления задачами на чистом Go (только стандартная библиотека) с асинхронным логированием через канал.

## Что внутри

- **CRUD** на `net/http` с маршрутизацией Go 1.22+ (`GET /tasks/{id}`).
- **Потокобезопасное хранилище** в памяти на `sync.RWMutex`, стабильная сортировка по ID.
- **Асинхронный логгер:** хендлеры кладут записи в буферизированный канал, запись идёт в отдельной горутине. Если буфер переполнен, запись отбрасывается и учитывается, а не блокирует запрос.
- **Graceful shutdown:** сначала сервер дожидается текущих запросов, затем логгер дописывает очередь, и только потом процесс завершается. Ни одна запись не теряется при остановке.
- **Валидация:** обязательное название до 200 символов, корректный ID, лимит тела запроса, ошибки в JSON.

## Запуск

```bash
go run . -addr :8080
# или
docker build -t task-api . && docker run --rm -p 8080:8080 task-api
```

## API

| Метод | Путь | Описание | Ответ |
|---|---|---|---|
| `POST` | `/tasks` | создать задачу | `201` + задача, заголовок `Location` |
| `GET` | `/tasks` | список, фильтр `?completed=true\|false` | `200` |
| `GET` | `/tasks/{id}` | одна задача | `200` / `404` |
| `PATCH` | `/tasks/{id}` | изменить статус `{"completed": true}` | `200` / `404` |
| `DELETE` | `/tasks/{id}` | удалить | `204` / `404` |

```bash
curl -X POST localhost:8080/tasks -d '{"title": "Изучить Go"}'
# {"id":1,"title":"Изучить Go","completed":false,"created_at":"2026-10-05T15:00:00Z"}

curl -X PATCH localhost:8080/tasks/1 -d '{"completed": true}'
curl "localhost:8080/tasks?completed=true"
curl -X DELETE localhost:8080/tasks/1
```

Ошибки возвращаются как `{"error": "описание"}` с кодом `400`, `404` или `405`.

## Тесты

```bash
go test -race ./...
```

- **Хранилище:** CRUD, сортировка и фильтрация, 100 параллельных созданий без дублей ID.
- **Логгер:** порядок записей и полный сброс очереди при закрытии; `Log` не блокируется, когда писатель завис.
- **API:** полный жизненный цикл задачи и табличные тесты на все ошибки валидации.

## Структура

```
main.go      запуск и graceful shutdown
handler.go   HTTP-хендлеры и валидация
task.go      модель и хранилище
logger.go    асинхронный логгер
```
